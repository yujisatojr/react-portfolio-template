## 🛠️ Development

### Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

### Building for Production

To create an optimized production build:

```bash
npm run build
```

### Deployment

This portfolio is configured for deployment to GitHub Pages:

```bash
npm run deploy
```
